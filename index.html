Маршрут из 5–7 статей Википедии от простого к сложному. Введите тему, уровень и язык.

Построить маршрут

До 100 символов. Можно на русском или английском.

Если это не та статья — выберите из списка выше. Иначе продолжаем.

Кандидаты

    Маршрут изучения

      Как это работает

      1. Находим стартовую статью в Википедии (точное совпадение → поиск, топ-5 на выбор).
      2. Берём ссылки из вступления статьи = кандидаты.
      3. Собираем данные кандидатов (описание, вступление, просмотры).
      4. Просим бесплатную модель выбрать 5–7 статей по уровню. При исчерпании лимита — упрощённый режим без ИИ.

      Ограничения MVP: маршрут только из ссылок вступления одной статьи; оценка сложности — по краткому описанию.

      Данные: Википедия, лицензия CC BY-SA 4.0. Маршрут составлен автоматически, пояснения сгенерированы ИИ; не заменяет консультацию врача или юриста.

      При нагрузке тема запроса может обрабатываться сервисом Google Gemini (бесплатный уровень может использовать запросы для улучшения моделей).

      Бесплатный пул LLM — десятки–сотни маршрутов в день. При исчерпании показывается упрощённый маршрут. Пул сбрасывается в 00:00 UTC (10:00 по Владивостоку).
