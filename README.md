# Финансовая система — Семён

Офлайн веб-приложение учёта личных финансов. Вносишь операции — балансы, конверты, долги, лимит на день, цели и архив считаются сами.

**Открыть в интернете:** https://gremel222.github.io/Finans/

Данные живут **только в браузере** (localStorage). Интернет после первой загрузки не нужен: это PWA.

## Запуск

```bash
npm install
npm run dev
```

Сборка для офлайн-установки:

```bash
npm run build
npm run preview
```

На телефоне: открыть → «На экран Домой». Резервная копия JSON — в **Настройки**.
