# Вики-навигатор знаний

Сайт: вводите тему — получаете 5–7 статей Википедии от простого к сложному. Без аккаунтов, без Cloudflare, без ИИ.

## Как открыть

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Или просто откройте `index.html` в браузере.

## Как пользоваться

1. Тема (до 100 символов), уровень, язык Википедии.
2. Кнопка **Построить маршрут**.
3. Если статья найдена точно — маршрут сразу, можно нажать **Не то?** и выбрать другую.
4. Если совпадения нет — список из поиска, выберите статью.
5. **Перестроить** — другой набор из тех же кандидатов (до 3 раз).

## Что внутри

- `index.html`, `style.css` — страница
- `src/wiki.js` — запросы к Википедии
- `src/fallback.js` — порядок статей по уровню
- `src/main.js`, `src/ui.js` — форма и карточки

Тесты: `node --test tests/*.test.mjs` (нужен Node.js 18+).
